Chaos Triangle

Best spots:

Click the picture to zoom in on that spot. Shift+click or right click zooms out. Every pixel is a number c. We start with z = 0 and keep doing z = z*z + c. If z flies off to infinity the pixel gets a color based on how fast it flew off. If it never does, the pixel is black.

This is the chaos game. There are 3 corners. We start anywhere, pick a random corner, jump halfway to it, and put a dot. Then we do it again and again. It looks like it should be a mess but a Sierpinski triangle shows up.
